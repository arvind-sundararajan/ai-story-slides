Introduction

GradientHQ built parallax to host local LLM.

Parallax is an open-source project developed by GradientHQ, with the initial version 0. 0. 1 released in 2025/10. The project utilizes P2P communication powered by Lattica, a GPU backend powered by SGLang and vLLM, and a MAC backend powered by MLX LM.

This architecture enables parallax to host local LLM on personal devices, providing cross-platform support and pipeline parallel model sharding. The use of paged KV cache management and continuous batching for Mac, along with dynamic request scheduling and routing for high performance, sets parallax apart from other solutions.

The specific problem parallax was built to solve is the need for a scalable and efficient way to host local LLM on personal devices, while also providing cross-platform support. This is achieved through the use of pipeline parallel model sharding, which allows for the distribution of model components across multiple devices. Additionally, parallax provides paged KV cache management and continuous batching for Mac, which enables efficient memory management and processing. The project also supports dynamic request scheduling and routing for high performance, making it suitable for a wide range of applications.

From a technical standpoint, parallax is distinct from other solutions due to its use of Lattica for P2P communication, SGLang and vLLM for the GPU backend, and MLX LM for the MAC backend. These design decisions enable parallax to provide a unique combination of scalability, efficiency, and cross-platform support. The project also provides a range of configuration options, including host, max-sequence-length, max-num-tokens-per-batch, enable-prefix-cache, and model, which can be customized to suit specific use cases.

The target audience for parallax includes developers and researchers who need to host local LLM on personal devices, while also requiring cross-platform support and pipeline parallel model sharding. The project's use of paged KV cache management and continuous batching for Mac, along with dynamic request scheduling and routing for high performance, makes it suitable for a wide range of applications, including multi-platform chat integration, persistent memory, and full system integration. The project's open-source nature and customizable configuration options also make it an attractive choice for developers who need to tailor the solution to their specific needs.
