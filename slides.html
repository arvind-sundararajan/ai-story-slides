Introduction

GradientHQ built Parallax to host local LLM on devices.

Parallax is a technical solution developed by GradientHQ, with the initial version 0. 0. 1 released in 2025/10. The specific problem it was built to solve is hosting local LLM on personal devices, which requires efficient pipeline parallel model sharding, paged KV cache management, and dynamic request scheduling and routing.

The architecture of Parallax is based on P2P communication powered by Lattica, with a GPU backend powered by SGLang and vLLM, and a MAC backend powered by MLX LM. This design allows for cross-platform support and high-performance capabilities. The use of Lattica for P2P communication enables efficient data transfer between nodes, while the GPU backend powered by SGLang and vLLM provides accelerated processing capabilities.

Parallax is technically different from alternatives due to its use of pipeline parallel model sharding, which allows for efficient processing of large models, and paged KV cache management, which enables continuous batching for Mac devices. Additionally, the dynamic request scheduling and routing capabilities of Parallax enable high-performance processing. The configuration keys for Parallax include host, max-sequence-length, max-num-tokens-per-batch, and enable-prefix-cache, which provide flexibility in customizing the solution for specific use cases.

The target audience for Parallax includes developers and researchers who require a high-performance solution for hosting local LLM on personal devices, with cross-platform support and efficient processing capabilities. The installation steps for Parallax include running the parallax run command, joining the network with the parallax join command, and installing the required dependencies, including Node. js and Python. The use cases for Parallax include hosting local LLM on personal devices, pipeline parallel model sharding, paged KV cache management, and dynamic request scheduling and routing for high performance.
